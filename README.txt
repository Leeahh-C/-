台灣鐵路環島大富翁｜手機抽卡網站

使用方式
1. 直接開啟 index.html 可預覽。
2. 建議上傳整個資料夾到 GitHub Pages、Netlify 或 Cloudflare Pages，即可取得六人共用網址。
3. iPhone 可在 Safari 點「分享」→「加入主畫面」，使用起來像 App。

目前內容
- 機會卡 36 張
- 命運卡 36 張
- 任務卡 32 張
- 同一牌組抽完前不重複
- 自動保存抽牌進度與最近 50 筆紀錄
- 可一鍵重洗全部牌組
- 支援離線快取（需先以網址開啟一次）

修改卡片
用文字編輯器開啟 index.html，搜尋「const decks」，即可修改三個牌組的文字。
